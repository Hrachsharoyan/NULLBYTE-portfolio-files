NULLBYTE — Hrach's cybersecurity learning portfolio

FILES

- index.html Main page and content
- main.css Main visual system (cyber-Japan / neon terminal theme)
- animation.css Motion and reveal effects
- main.js Boot screen, mobile navigation, scroll reveals, and contact form behavior

RUN LOCALLY

1. Put all four files in the same folder.
2. Open index.html directly, or open the folder in VS Code and use Live Server.
3. Do not move the CSS/JS into src/css or src/js unless you also update the paths in index.html.

CONTACT FORM
The form validates its fields and opens a pre-filled email draft addressed to Hrachprofessional@hotmail.com. It does not send mail from a server.
